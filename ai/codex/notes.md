<summary><strong>이 AGENTS.md는 Codex와 Claude Code의 세 가지 가장 짜증나는 습관을 수정합니다:</strong></summary>

아직 아무도 사용하지 않는 프로젝트를 위해 뒤로 호환되는 코드를 작성하는 것,  
더 이상 필요하지 않은 오래된 코드와 문서를 절대 삭제하지 않는 것, 그리고 버튼 색상을 바꾸기 위해 테스트 더미를 추가하는 것.

몇 달 동안 매일 그것들을 사용한 후, 첫날부터 거기에 넣고 싶었던 라인들은 맨 위에 있는 것들입니다:  
프로젝트에 아직 실제 사용자가 없다면, 호환성과 마이그레이션을 건너뛰고, 바로 **가장 간단한 작동하는 코드**로 가세요.

그 다음은 네 단계 루프: 문서 먼저 → 테스트 → 가장 작은 구현 → 정리.

이걸 당신의 AGENTS.md에 복사해서 붙여넣으세요

```
# AGENTS.md
아직 실제 사용자가 없는 프로젝트에만 적용됩니다.

## 기본 규칙
- 하위 호환성 없음, 데이터 마이그레이션 없음
- 변경한 것을 작동하는 가장 간단한 코드로 교체하고, 동일한 변경에서 모든 호출자를 업데이트하세요

## 모든 변경, 이 순서로
1. 문서 먼저: 관련 문서를 업데이트하고 코드나 서로 모순되지 않도록 확인하세요
2. 테스트: 동작을 테스트하고, 작은 세부 사항은 건너뛰며, 먼저 실패하는 것을 확인하세요
3. 최소 구현: 테스트를 통과할 만큼만 작성하고, 추가적인 것은 아무것도 하지 마세요
4. 정리: 이 변경으로 인해 사용되지 않게 된 코드, 파일 및 문서를 삭제하세요. 확실하지 않음? 저에게 물어보세요

## 하지 마세요
- 오래된 코드를 "혹시 모르니" 보관하지 마세요
- 저에게 묻지 않고 데이터베이스를 삭제하거나 데이터를 재설정하지 마세요

## 완료라고 말하기 전에
- 테스트를 실행하고 출력을 직접 읽어보세요
- 삭제한 것을 저에게 말하세요
- 검사를 실행하지 않았다면, 그렇게 말하세요

## 내가 당신을 수정할 때
- Lessons 상단에 줄을 추가하세요: "X일 때, Y를 하세요"
- 같은 실수를 두 번 하면 그 레슨이 불명확합니다. 다시 작성하세요, 또 다른 것을 추가하지 마세요
- 20개 이상의 레슨? 중복을 병합하고, 오래된 것을 삭제한 후 저에게 보여주세요
```
