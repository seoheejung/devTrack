# 오픈소스

<details>
<summary><strong>믿기지 않을 정도로 무료인 오픈소스 AI 도구 10선</strong></summary>


요즘 세상에 정보 없어서 못 한다는 건 진짜 핑계인 것 같음. 유료 서비스 뺨치는 오픈소스 툴들이 이렇게 널려 있는데 아직도 구독료만 꼬박꼬박 내고 있으면 좀 반성해야지. 특히 Cline이나 ComfyUI 같은 건 이미 아는 사람들은 다 쓰는 검증된 툴이라 일단 깔고 보는 게 맞다. 남들 돈으로 해결할 때 우린 기술로 승부해서 마진 남기는 게 진짜 승자지

1. Fooocus
Midjourney의 대안. 자신의 노트PC에서 작동하며, 3번 클릭으로 첫 이미지를 완성할 수 있음.

[https://github.com/lllyasviel/Fooocus](https://t.co/GpU6nzoxX5)

2. ComfyUI
프로 AI 아티스트가 본격 제작에 사용하는 이미지 생성 도구. 스튜디오에서도 채택된 진지한 스펙.

[https://github.com/comfyanonymous/ComfyUI](https://t.co/uDdXEinLVB)

3. Ollama
ChatGPT를 자신의 머신에서 실행할 수 있음. 인터넷 불필요, API 과금 제로, 명령어 하나로 설치 완료.

[https://github.com/ollama/ollama](https://t.co/wvdidJsTO9)

4. OpenVoice
10초 음성으로 어떤 목소리든 복제 가능. MIT와 MyShell 제작, 라이선스는 상업 이용 OK.

[https://github.com/myshell-ai/OpenVoice](https://t.co/y7cruci2Zv)

5. Penpot
Figma의 대안. 실시간 공동 편집 기능 포함, 브라우저에서 작동하며 자체 호스팅도 가능.

[https://github.com/penpot/penpot](https://t.co/FAH6DlULfj)

6. AppFlowy
Notion의 대안으로, 데이터는 전부 자신의 머신에 남음. Rust로 만든 로컬 퍼스트 설계.

[https://github.com/AppFlowy-IO/AppFlowy](https://t.co/B9Iopyikr8)

7. n8n
Zapier의 대안. 1600개 이상의 연동과 전용 AI 노드 탑재. 자체 호스팅 시 워크플로 무제한.

[https://github.com/n8n-io/n8n](https://t.co/pvJGzLdiyo)

8. Cal(.)com
Calendly의 대안. 유료 버전보다 기능이 많고, 클라이언트용 화이트 라벨화도 가능.

[https://github.com/calcom/cal.com](https://t.co/G67KBojy2o)

9. Supabase
Firebase의 대안으로, 게다가 스스로 소유 가능. Postgres·인증·스토리지·Realtime·Edge Functions가 모두 포함.

[https://github.com/supabase/supabase](https://t.co/UWh80N52tL)

10. Cline
VS Code 내에서 작동하는 Cursor의 대안. 파일을 읽고, 코드를 편집하며, 기능을 완성까지 이끌어줌.

[https://github.com/cline/cline](https://t.co/A1AQmzRgB2)

SaaS로 다 맞추면 월 300~500달러(약 4.8~8만 엔) 수준이 들 텐데, 이게 전부 무료로 영구히 쓸 수 있음.
