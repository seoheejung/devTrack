# Redis

속성: Backend

#### 현대 데이터베이스가 극한의 처리량을 희생하지 않으면서 내구성을 어떻게 보장하는지에 대한 깊이 있는 탐구

1. 왜 싱글 스레드 Redis가 빠른가
2. TCP 에코 서버 작성
3. 와이어 프로토콜
4. RESP 구현
5. PING 구현
6. 이벤트 루프 이해
7. 이벤트 루프 구현
8. GET, SET, TTL 구현
9. DEL, EXPIRE, 정리 구현
10. 키 제거 전략과 첫 번째 제거 구현
11. 명령 파이프라이닝 구현
12. AOF 영속성 구현

데이터베이스 내부, 파일 시스템, 또는 탄력적인 백엔드 인프라 구축에 열정을 가진 누구에게나 이 시리즈는 고성능 데이터 저장소를 마스터하는 데 필요한 실습적 직관을 제공합니다.

백엔드 개발자라면 키핑해둘 만한 Redis 인터널 시리즈임. AOF 지속성 메커니즘을 소스 코드 분석부터 직접 구현까지 다루는데, 파일 디스크립터 제어랑 동기화 전략 같은 저수준 지식 쌓기에 딱 좋음. API 호출 수준을 넘어 데이터가 실제로 디스크에 박히는 과정을 이해해야 진짜 고성능 저장소를 다룰 수 있음.

#### 바이브코딩하면서 Redis부터 붙이는 사람이 많습니다.

그런데 놓치는 게 있습니다.

Redis는 성능을 높이는 만능 도구가 아닙니다.

용도가 분명합니다.

- 로그인 세션
- 캐시
- 작업 큐
- Rate Limit
- 실시간 상태

이런 기능이 없다면 대부분은 PostgreSQL이나 MySQL만으로 충분합니다.

Redis는 일단 넣는 기술이 아니라, 필요할 때 넣는 기술입니다.
