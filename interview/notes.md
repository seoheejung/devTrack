# 인터뷰 질문

속성: Interview


<details>
<summary><strong>준수할 인터뷰 분류 체계</strong></summary>


1. **아키텍처**: 분산 구조, 확장성, 설계 선택 판단
2. **성능/트러블슈팅**: 실제 장애 대응 능력, 병목 분석
3. **DB/데이터**: 데이터 구조, 처리 및 저장 전략
4. **API/HTTP**: API 설계 원칙 및 프로토콜 이해
5. **보안**: 입력 검증, 인증/인가, 세션 관리
6. **인프라/운영**: 실제 운영 환경 대응, DevOps, 클라우드
7. **언어/CS**: 기초 개념, 런타임 메커니즘, OS/NW
8. **메타(사고력)**: 개발자의 역할 정의 및 문제 해결 태도


</details>

- **확장**: 실제 적용 사례, 대안, 또는 잠재적 리스크 검토


</details>
